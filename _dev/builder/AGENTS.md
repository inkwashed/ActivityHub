# Builder Lab

Read docs/WORKFLOW.md and docs/STYLE-GUIDE.md first. This is a local, non-live staging surface, not a student lesson. Do not link it from the public homepage or deploy it. `_dev` is excluded from GitHub Pages/Jekyll; other publishing systems must exclude it explicitly.

Consume shared engines/styles directly. Keep unapproved layout experiments scoped to `.builder-lab`; promote approved behavior to shared implementations only with an explicit consumer rollout and tests. Do not copy a complete production app and allow it to diverge. Example artwork may reference the Sandwich catalog; no production app may depend on this lab.

The Share dialog is intentionally a sample, not export. Keep that clear. Reset and the other interactions are real test fixtures. Update README gaps/verification when behavior is approved or migrated.
