# Class Supplies

Entry: `apps/class-supplies/index.html`. Let’s Try! 2, Unit 5: “Do you have a pen?” Listed on the homepage under Let’s Try! 2 Unit 5; publishing is handled separately.

Selected-item question audio uses the shared approved “Do you have a/an” prefix followed by the item recording, with no display-format change. All 13 singular items are supported. A selection change cancels pending playback; the empty question and missing/failed recordings use full-question browser speech. Prefix listening review and automated sequencing/fallback checks passed; physical iPad/Safari playback remains unverified. Generation and provenance are owned by `assets/audio/README.md`.

LEARN is one building flow. Tap a supply to toggle it; one of each type has a fixed, recognizable position. The hard-sided case is shown straight from above, with aligned rectangular lid and tray interiors, visible hinges and a front clasp. The ruler uses a slim profile and fits within the lid rim. Pencils, colored pencils, pens, markers and rulers appear horizontally in both palettes and use the same default artwork size in LEARN and PLAY (the shared per-item defaultScale is currently 1.30× for writing tools and 1.56× for the ruler); new PLAY pieces start horizontal; saved PLAY rotations remain unchanged. The ruler sits lengthwise inside the lid; pencils, pen and marker lie horizontally in the tray, with the eraser and upright glue stick beside them. LEARN rotations also apply to Share; PLAY retains independent transforms. The enlarged bound notebook and flat calendar sit side by side below the case, using matching default sizes in LEARN and PLAY. The sharpener and magnet sit at either end of the lid; the stapler sits inside the tray. The pencil case is always present, completing the 13 vocabulary items. Its color is chosen through the same color controls as other supplies.

The question follows the selected item in LEARN and PLAY, returns to “Do you have a …?” when selection clears, and uses a/an (for example, “Do you have an eraser?”). Its pronunciation button reads the current question. The output area contains only the inventory sentence; the Yes/No response line is intentionally omitted. The app does not ask questions or decide which response a student should say. LEARN inventories the types present using “I have…” and a/an; PLAY uses numeric counts grouped by item and color. LEARN EASY omits color words and hides color editing; HARD enables scene selection/swatches and adds colors before nouns (including “an orange …”). PLAY always enables color editing and color words, showing the difficulty switch locked to HARD. Returning to LEARN restores its previous difficulty. Color changes immediately update output and Share captions; saved palettes survive EASY/HARD switches.

PLAY reuses CreativeBuilder for drag/pinch, size, rotation, flip, duplicate, TOP, delete, keyboard movement and ordered picking. Each mode keeps independent supplies and colors. Each PLAY piece has its own color; duplication preserves that color. Output groups pieces by item and color with counts and singular/plural nouns. The fixed case is a backdrop in both modes. Reset clears only the active mode and returns its colors to defaults.

The app header and browser favicon use a red pen pointing tip-down. Original SVG artwork and fixed LEARN coordinates live in config.js. The eraser is white with a text-free blue/white/black sleeve by default; its color control changes only the colored sleeve band. The glue stick also defaults to white with a blue band near its ribbed twist base; its color control changes the band, leaving the cap and body white. Saved color choices are retained. A plain pencil retains a graphite tip when its barrel is recolored; colored pencils retain colored cores. Shared controls, tokens, icons, viewport/workspace, pronunciation, language dialog, QR and photo lifecycle are consumed directly. No shared behavior was changed. Missing vocabulary recordings use the shared browser-speech fallback.

Saving wraps BuilderAutosave with validated per-mode color palettes and selected color target. Storage ID: class-supplies. Share exports the visible frame using the same SVG art and back-to-front PLAY transforms; no upload. The app QR points to the eventual canonical public path, which is not published by this prototype work.
